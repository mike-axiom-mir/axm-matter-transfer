# axm-matter-transfer

Speculative research into continuous-adjacency matter transfer. No physical
macroscopic matter-transfer mechanism is established.

The preserved research body defines the claim ceiling, transfer-mode
distinctions, and research gates. The first executable experiment reproduces a
published toy geometry without promoting it into engineering evidence:

```bash
python3 experiments/ellis_wormhole.py run \
  --input experiments/fixtures/ellis_zero_mass_v1.json
```

See [the executable experiment guide](experiments/README.md) and the current
[continuous-adjacency crosscheck](research/2026-09-02-continuous-adjacency-crosscheck.md).
